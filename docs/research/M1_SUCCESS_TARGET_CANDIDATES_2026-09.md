# M1 成功 token 目标候选：定义、近邻与有限建议

**审计日期：2026-09-29。** 本文落实 issue #13，只判断哪些成功成本目标值得进入下一阶段核实。研究目标保持为“给定运行前可用的任务和 agent 配置信息，预测成功完成所需的 token 数量”；本文不替换该目标，也不证明某候选已可识别、可训练或有预测增量。

**唯一建议：`NO_SUPPORTED_CANDIDATE`。** A 是可观察目标的参照定义，但现有近邻比较没有建立成功条件筛选之外的重要研究差异；可观察性和字段支持都不能补出这个概念缺口。B 与 A 在估计对象上有重合，不能当成互斥的替代贡献。C 仍受未建立的延续/删失条件限制。当前不建议因本报告启动 M2。

issue #13 允许的三种结论为 `RETAIN_ONE_FOR_M2`、`NO_SUPPORTED_CANDIDATE`、`TARGETED_EVIDENCE_HOLD`；本文只选择第二项，不并列保留或悬置结论。

## 三个可评价候选

### A — 最终成功的一次运行，其观测 token 终点

- **单位与条件：** 一条 benchmark 运行 `r`，绑定任务 `x` 和冻结的既有 agent 配置 `a`；仅对按原 benchmark evaluator 判定最终成功的运行定义标签 `U_r`。
- **目标量/群体：** 标签是单条成功运行从原始运行开始到记录终点的 actor token 用量 `U_r`。跨任务学习时可讨论合法运行前特征给定后的成功运行条件预测函数；A 本身只定义逐运行实现值，不预设预测损失、函数形式或群体汇总量。
- **预测时点、接收方与用途：** 概念上的运行前参照是：预算规划者/实验者依据合法任务及配置信息估计一次尝试若最终成功的 token 终点。它不预测成功概率，也不承诺能让运行成功。该条件成本对独立成功质量已可接受时的配置比较，或对成功后资源规划，是否形成重要且不同于普通成功过滤的决策问题，尚未论证。
- **成功的角色：** `S=1` 用来定义目标标签和目标评价群体；它不得作为运行前输入。要在未来部署中只对未知是否成功的任务预测，目标群体如何从运行前可见资料定义仍需另行讨论，不能将未来成功标记泄漏给预测器。
- **已知事实与假设：** 成功运行的终点 token 在原则上可直接观察；M0 汇总存在 161 个合格成功终点/81 个任务身份。候选假设同一条日志能对齐任务、配置、token 角色及 evaluator 成功事实，而且所需输入在运行前已存在。当前没有 M2 支持度检查，不能说这些字段已足够。
- **用途失败/证伪：** 如果日志无法一致地给出 actor token、成功标签或运行前关联字段，目标不能评价；若任务/配置支持和共享结构假设不足，不能评价跨任务预测泛化。即使可评价，若它只是 TokenCast 一般终止消费任务的常规成功过滤，且这个过滤不回答重要的独立决策问题，则不支持独立贡献；本次因此不保留 A 进入 M2。

### B — 同任务、同配置的成功运行成本分布或代表统计量

- **单位与条件：** 固定任务 `x`、配置 `a` 与成功运行的生成机制；有限样本中的每条成功运行是观测单位，不把重试拼成一条轨迹。
- **目标量/群体：** 可以问成功运行条件分布 `F(U | x,a,S=1)`，或定义该分布的统计泛函，例如总体条件均值 `m(x,a)=E[U|x,a,S=1]`、中位数。对单次运行标签使用平方误差时，其风险最优预测函数正是成功群体条件均值；因此 A 的逐 run 标签与 B 的条件均值预测并不互斥。跨任务在明确的共享结构假设下学习 `m(x,a)` 不要求每个精确 task×agent 单元都有重复运行。有限重复样本均值/中位数是总体统计量的估计，不是总体本身。
- **预测时点、接收方与用途：** 运行前给固定任务和配置的规划者预测成功条件下的典型/期望资源需求，服务于跨任务/配置的成功成本规划；若用途仅是预测某条具体运行，则聚合量与决策需求不匹配。
- **成功的角色：** `S=1` 定义目标分布与评价样本，不作为运行前特征。这里的条件化与输入泄漏无关；只有把未来运行结果、实际 token 或成功判定放入特征才泄漏。
- **已知事实与假设：** D01 有四次独立运行且代码将四次 usage 固定除以 4 形成聚合值，但实际 ground-truth CSV、行生成链及其上游成功筛选未知；不能把 D01 四次均值直接称作成功条件统计量，也不能断言其均值输入造成泄漏。B 必须说明所选条件统计量、跨 task/config 的共享结构和评价目标。
- **用途失败/证伪：** 重复不足会限制精确 task×agent 单元内分布/离散度的直接估计、有限样本均值的稳定性和独立单元内核验；它不自动排除在明确结构假设下跨任务学习条件函数。若结构假设不可信、任务/配置覆盖无法支撑所需泛化，或估计目标没有独立重要用途，则不支持该候选。即便估得某统计量，若它只是对已有每次终止消费预测再做普通聚合且不带来独立重要用途，不构成贡献候选。

### A 与 B 的统计关系

A 指逐运行随机标签 `U`，B 可指该标签在成功群体下的条件分布或其统计泛函。若采用平方损失，最优预测函数是条件均值 `E[U|X,A,S=1]`，所以 A 的学习问题与 B 的条件均值并不互斥；均值是否是所需决策量仍须另行说明。统计课讲义给出平方误差下回归函数为条件期望，并指出估计该函数依赖从过程取得的多次实现。[Model-Agnostic Prediction, “Regression and Conditional Expectations”](https://www.stat.cmu.edu/~cshalizi/dst/20/lectures/24/lecture-24.html)。共享结构可在不同 task/config 之间部分汇聚，但结论依赖可辩护结构假设和分组评价设计；不要求每个精确 task×agent 单元重复，也不保证任意数据都足够。

### C — 同一原始运行规则继续到成功的潜在 token 成本

- **单位与条件：** 一条原始运行路径 `r`，在同一任务、agent/scaffold、初始状态、工具/环境、提示和策略规则下，从真实起点延续。`T_r^success` 是按原 evaluator 第一次判为成功时的累计 actor tokens。
- **目标量/群体：** 若运行在 `U_r` 被行政性截断，目标是同一条未被中断路径本会到达首次成功时的 token 数；其条件群体必须明确（例如原规则最终能成功的路径），不能将“最终可成功”默认为所有失败都满足。起始后重置/独立重试不是同一条潜在路径，不允许拼接成“继续到成功”。
- **预测时点、接收方与用途：** 运行前为资源计划者预测在原规则不被外部截断时、同一尝试到达首次成功所需资源。
- **成功的角色：** 反事实成功定义目标终点；实际最终成功、完整前缀首次成功、行政停止及停止时间的可观测关系是识别问题。成功状态与未来终点不进入预测输入。
- **已知事实与假设：** 需要同路径可延续、`T>U`、终止原因确属外部截断、首次成功可见，以及可辩护的删失机制等。M0 四项判断全部 unknown，训练获准行数 0；自然失败不能按已知右删失处理。
- **用途失败/证伪：** 若自然失败改变路径/策略、停止为吸收性失败、没有同规则可延续证据、或记录看不到首次成功，则潜在成本不由这些日志识别。不能用独立 rerun、最终成功标签或事后插补补造反事实。当前不保留 C 为候选，也不提出 survival 方法。

## 最强反例及候选判断

**最强反例：TokenCast 加上 D01 的自估/聚合结果。** TokenCast 已明确覆盖运行前、task-level 的实际终止消费预测，含同一任务重复运行、task-group split 和 Self-Prediction/history baseline；D01 已展示执行前自估和多运行均值。最有力的反对解释是：对于一个计划成功完成的尝试，直接用一般 run-consumption predictor，再在训练/评价中只保留成功运行，可能已经得到 A；对 B 可进一步做常规分组聚合。成功筛选本身是目标定义的改变，但不自动带来科学重要性或审稿人可辨认的增量。

对此只能作有限回应：近作论文直接定义的预测对象是通常终止/记录到的消费；它们没有在固定公开证据中明确建立“同一 agent 条件下只预测成功运行 endpoint”的目标及其评价用途。但实现训练行筛选的 unknown 不应被当作不存在该做法的证据，也无需无限等待代码公开。条件成功成本只有在资源规划/配置比较中回答了一个不可由现有一般消费预测加简单筛选解决的重要问题，才可能成为有意义差异；本报告尚未证明这个前提。可观察的 A 因而只是参照定义，不足以保留候选。B 与 A 的条件均值预测在平方误差下重合，其他条件统计量虽不同，也未显示独立重要用途。C 的必要机制目前不具证据资格。**结论为 `NO_SUPPORTED_CANDIDATE`：现有材料支持一个清楚的待定义问题和强近邻反例，却不支持任何一个候选作为当前 M2 入口或独立研究贡献。**

## 翻转条件与阶段边界

- **A/B 当前不支持候选保留：** 这不是因精确 task×agent 重复不足自动否定一般回归，也不由字段审计决定。除非出现具体而重要的决策问题，证明常规终止成本预测加成功筛选/共享结构估计不足，且差异可被证伪，否则继续保持 `NO_SUPPORTED_CANDIDATE`。未来预测效果或跨划分稳定性不能弥补缺失的研究问题。
- **B 的有限重复限制：** 需区分条件函数的跨任务学习与精确单元统计。单元重复不足限制经验条件分布、离散度、有限样本均值的直接估计和单元内核验；在可辩护共享结构假设、任务/配置覆盖和适当分组评价下，不要求每个精确 task×agent 单元重复才能学习条件函数。是否成立取决于数据与假设，不在本报告选择损失或训练。
- **C 可重开条件：** 固定现有路径和记录证明候选行确属外部停止，并满足同一延续规则、首次成功可见及删失识别条件。四项未知没有满足前，不将 C 交给训练。
- **有限停止规则：** 不等待未来作者代码来填补概念差异；在未提出重要、可证伪的问题前，不启动 M2 候选支持审计、不补采、不拼重试、不训练。若后续独立决策提出问题并另行批准字段审计，再判断现有支持能否回答它；支持不足时记录限制，不把技术可行性包装成贡献。

## M2 与数据边界

本报告结论不是 M1 通过，也没有建议立即启动 M2。数据读取与公开发布是不同权限：用户已授权范围内的只读检查，只有在研究问题获得足够支持、并经后续任务明确批准后，才可受控读取最少必要记录；公开只允许聚合证据，不公开逐题真值或原始/受限数据。当前标签/训练包未批准，训练仍由师兄负责。

M0 已知边界继续有效：逐 run 成功 endpoint、成功条件函数/分布与潜在成功 estimand 分开；同题同 agent/seed/variant/来源重复不得跨分区；四项删失事实仍 unknown、训练资格为 0。未来 M2 是否有可评价问题须由后续决策结合真实字段和支持判断；不在此预定损失、基线、校准或效果实验。本次结论不批准处理原始数据、建立标签或训练包、训练或论文写作。
